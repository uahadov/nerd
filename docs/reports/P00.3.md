## Aşkarlanan problemlər və düzəlişlər

1. CLI layihə yaratma cəhdi müşahidə müddətində nəticə vermədi və yalnız həmin proses dayandırıldı.
   Rəsmi Editor-un createProject yolu exit 0 ilə layihəni yaratdı. Unity Cloud/GitHub layihəsi açılmadı.
2. İlk compile-da BuildReport int/uint uyğunsuzluğu və köhnəlmiş version-control API-si vardı;
   uyğun API/tiplər ilə düzəldildi. Son compile və build C# diaqnostikası boşdur.
3. Sistem Java-sı PATH-də olmadığı üçün ilk ayrıca apksigner cəhdi exit 127 verdi.
   Yalnız yoxlama prosesinə bundled OpenJDK yolu verildi; təkrar exit 0 oldu.
4. İlk preview callback-i PlayMode domain reload-da itirdi. SessionState ilə yalnız açıq
   preview sorğusu bərpa edilir. Preview erkən PlayMode-a keçdiyi üçün Search ilkin indexini
   qurmurdu; başlanma Editor ilkin yeniləmələrindən sonraya gecikdirildi.
   Son təmiz açılışda Search exception təkrarlanmadı və yeni screenshot alındı.
5. Əvvəlki GUI prosesi tam bağlanmadan retry duplicate-project dialoqu yaratdı.
   Agentin öz açılışları bağlandı; lock qorunaraq kənara köçürüldü, recovery ehtiyatları saxlandı.
   Son yoxlamadan əvvəl Editor öz API-si ilə exit 0 bağlandı və lock təmizləndi.
   Mənbə və Git tarixçəsi silinmədi; son retry tək Editor ilə açıldı.
6. Bəzi başlanğıc loglarında lisenziya access-token yenilənməsi qeydi görünür.
   Lokal Unity Personal entitlement və real compile/test/build işlədi; yeni login və ödəniş edilmədi.

7. Android build Unity 6 üçün yeni .utmp native cache qovluğu yaratdı. Commitdən əvvəl
   fayl siyahısında aşkarlanıb .utmp/.gradle/.cxx və recovery üçün ignore/probe qoruması əlavə edildi.
   Cache və bərpa faylləri silinmir, Git-ə daxil edilmir.

Root cause əsaslandırması və ilkin cəhdlərin məhdudiyyətləri D010–D013 qeydlərindədir.
Garuda/KDE/Intel-də bu real sınaq işləyib; bu, Unity-nin həmin konfiqurasiyaya ümumi rəsmi dəstəyi iddiası deyil.

# P01.4 — qələbə, partiyalar və qayda müqaviləsi

Tarix: 2026-11-03. Status: **AWAITING_HUMAN_APPROVAL**.

## Görülən iş

Master Plan P01.4 üzrə ayrıca, Unity-dən asılı olmayan Nard.Match assembly-si hazırlandı:

- MatchSession: Created → Rolling → Moving → TurnCommitted → Rolling; qalib gedişdə Finished.
  İlkin bərabərlik, uzun/qısa ilk atış fərqi, rol/versiya, tam növbənin atomik qəbul/rəddi,
  ilk növbə flag-i və növbəti oyunçunun seçimi mövcud mühərriklərə uyğun idarə edilir.
- GameResult: bitmiş mövqedən qalib, WinKind və Points ayrı çıxarılır. Adi=1, mars=2,
  yalnız qısada koks=3. Qoşa zərin qiyməti nəticə xalını artırmır.
- MatchSeries: 1/Best of 3/5; müvafiq olaraq 1/2/3 partiya qələbəsi tələb edir.
  Qələbə sayı və partiya xalları ayrıdır; təkrar GameId və başqa rejim/versiya rədd edilir.
- RuleContract: uzun və qısa qayda versiyaları dəqiq yoxlanır; uyğunsuzluq səssiz qəbul edilmir.
- RatingPolicy: yalnız random + ranked + etibarlı nəticə təsdiqi uyğun sayılır.
  Bot, özəl və casual uyğun deyil. Bu yalnız eligibility predikatıdır; reytinq hesablaması,
  server təsdiqi, backend və məlumat yazılması hazırlanmayıb.

Snapshot-lar dəyişməzdir; rədd edilmiş təklif əvvəlki vəziyyəti saxlayır. Zərlər girişdən gəlir,
modul təsadüfi nəticə yaratmır. TurnCommitted lokal qayda qəbuludur, online server təsdiqi deyil.
Rolling zamanı engine position əvvəlki qəbul edilmiş mövqedir; cari oyunçu MatchSession.Player-dir.
SupplyRoll yeni oyunçunun aktiv position-unu yaradır. Preview/undo P02.4-də qalır.

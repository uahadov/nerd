## Nəticə və əhatə

Uzun nərd üçün verilmiş mövqe və zərlərdən bütün qanuni tam növbələri hesablayan modul hazırdır.
Başdan çıxış, hər iki oyunçunun ilk şəxsi 3/3–4/4–6/6 istisnası, tutulmuş xana,
altılıq/döngə, maksimum zər istifadəsi, yüksək zər, evə yığılma/çıxarma və son daş yoxlanır.
İstifadəçinin istədiyi adi/mars nəticəsi uzun mövqedən soruşulur; seriya və reytinq sistemi yoxdur.

İki runtime faylı var: [LongPosition](../../unity/Assets/Game/Rules/LongPosition.cs)
giriş/çıxış massivlərini kopyalayan dəyişməz vəziyyət saxlayır;
[LongNardeRules](../../unity/Assets/Game/Rules/LongNardeRules.cs) yalnız qayda hesablamasını aparır.
Nard.Rules.Long assembly-si noEngineReferences=true-dur; Unity, UI, animasiya, RNG, saat,
bot, saxlama və şəbəkə asılılığı yoxdur. RuleSetVersion long-az-gdd1-provisional.1 saxlanır.

Tam növbə təklifi TryApplyTurn ilə atomik yoxlanır: səhv olduqda giriş vəziyyəti və zərlər dəyişmir.
LegalTurns hər mümkün lokal addımı dörd zər hüququ bitənədək araşdırır, sonra maksimum
istifadə və yüksək zər şərtini tətbiq edir. Qoşada eyni qiymətli tokenlərin sırf nömrə
permutasiyası eyni oyun seçimidir; generator bir təmsil verir, validator digər unikal
slot sıralarını da qəbul edir. Oyun baxımından fərqli addım ardıcıllıqları saxlanır.

TryApplyLocalStep yalnız lokal addım analizi üçündür: təkbaşına tam növbə təsdiqi deyil.
P01.1-dəki move nümunələri bu müqaviləni, turn nümunələri tam növbə müqaviləsini sınayır.
Gələcək UI/server tam növbə üçün LegalTurns/TryApplyTurn istifadə etməlidir.
İlk növbə flag-lərinin növbəsonu yenilənməsi, növbə dəyişməsi, undo, tam matç state machine,
Best of 3/5 və reytinq uyğun sonrakı partların işidir.

Qısa mühərrik, yeni UI/taxta/ekran, animasiya, audio, bot və multiplayer yaradılmayıb.
Mövcud bootstrap səhnəsi, input, runtime, Editor alətləri, paketlər və ProjectSettings dəyişməyib.
STATE build sahəsi yeni P01.2 APK-ni göstərir; əvvəlki P00.3 qeydi historical_builds daxilində qorunur.
Açıq əsas Editor prosesinə toxunulmayıb; batch test/build ignored build/P01.2/unity mənbə surətində aparılıb.

1. Runner ilk nəticədə NUnit-in Skipped:Ignored başlığını ümumi xəta sayırdı,

   icazəsinə uyğun P01.2 sərhədi qoyuldu; qısa/UI/bot/server qadağaları saxlanıldı.
4. A01 inventarda NOT_STARTED görünürdü. Uzun mühərrik mövcud olduğundan yalnız status
   IN_PROGRESS oldu; xüsusiyyətin dəqiq mətni dəyişmədi və tam oyun DONE kimi göstərilmədi.
5. Köhnə APK yeni build çatışmazlığını gizlətməsin deyə runner əvvəlki P01.2 APK-ni
